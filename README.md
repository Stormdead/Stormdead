## Proyecto destacado

### [Retail Sales Intelligence](https://github.com/Stormdead/Retail-Sales-Intelligence)

Caso de análisis de ventas y rentabilidad para una distribuidora ficticia del Gran Concepción, construido con **Power BI, Power Query y DAX**.

[![Vista del resumen comercial de Retail Sales Intelligence](https://raw.githubusercontent.com/Stormdead/Retail-Sales-Intelligence/main/docs/images/resumen-comercial.png)](https://github.com/Stormdead/Retail-Sales-Intelligence)

- **Datos:** 3.000 líneas de ventas sintéticas de 2025, en pesos chilenos.
- **Análisis:** resumen comercial, productos, clientes y vendedores.
- **Modelo:** esquema estrella con dimensiones de producto, cliente, vendedor y fecha.
- **Documentación:** indicadores de referencia, conciliación de métricas y límites del conjunto de datos.

[Explorar el proyecto y sus capturas →](https://github.com/Stormdead/Retail-Sales-Intelligence)
